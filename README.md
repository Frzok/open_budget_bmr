
# Balta City Financial Analysis

Аналитический проект на основе финансовых данных Балтийского городского совета. Цель — выявить ключевые тенденции, визуализировать бюджетные статьи и продемонстрировать навыки работы с Python и Tableau.

---

## ✨ Цели проекта
- Создать понятную визуализацию доходов и расходов
- Показать динамику бюджета по годам
- Доказать опыт в ETL, визуализации и подготовке дашбордов

---

## 📃 Содержимое

```
balta_city_financial_analysis/
├── data/                    # Данные
│   ├── raw/                #   Сырьё
│   └── processed/          #   Обработанные данные (Tableau-ready)
├── notebooks/              # Jupyter ноутбуки
├── reports/
│   ├── figures/            # Графики
│   └── tableau/            # План и материалы для Tableau
├── tableau_exports/        # Скриншоты/экспорты из Tableau

└── LICENSE
```

---

## 🧰 Используемый стек
- **Python** (Pandas, Matplotlib, Seaborn)
- **Jupyter Notebook**
- **Tableau** (интерактивные дашборды)
- **Git** (версионирование)

---

## 🔢 Ключевые шаги
1. Получение данных из городского совета
2. Очистка и подготовка данных (ETL)
3. Перевод в длинную форму для Tableau
4. Разведочный анализ в Jupyter
5. Создание Tableau-дашбордов
